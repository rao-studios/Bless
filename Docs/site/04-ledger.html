What does the ledger prove?

On a log that notices when it has been changed, and holds nothing a patient said.

Every transition at the Gate writes one event to the ledger: a draft held, a petition viewed, a verdict given, a release handed out. Each event's hash covers its own fields and the hash of the event before it. Change any byte of any event and every hash from there on stops matching.

What verify finds

Ledger.verify walks the chain from the first event and names the first one that does not fit. A changed byte breaks that event's own hash. Re-hashing the changed event moves the break to the next one, whose previous no longer matches.

A dropped line or two swapped lines break the numbering. To hide a change, a forger must rewrite every later event; a copy of the last hash kept somewhere else gives that away.

What it records

The ledger knows ten kinds of event: submitted, viewed, decided, blessed, withheld, expired, withdrawn, released, dispatched, failed. Each names its petition, its actor when a person acted, the digest of the text it concerns, and a code.

A code is a word from Bless's own vocabulary, such as the ruling's kind, the release's basis or an error's name. It is never free text.

No words, only digests

The ledger holds no message and no reason. A text appears only as its SHA-256, which proves which words were held and which were sent without saying them. A withholding reason such as a test result would otherwise sit in a log every auditor reads.

The rule is checked, not trusted. The layering test fails if the ledger's folder reads a message's content. A ledger test withholds a reply with a diagnosis in its reason, then searches the log for it.

For engineers: where each piece lives
  • The ledger-chains trail goes from an append through the canonical bytes to the file and the walk back.
  • FileLedgerStore writes JSON lines, appended and flushed before each call returns, mode 0600. A ledger reopened over its file continues the chain.
  • The canonical layout is in Canonical.swift; CanonicalTests holds it to vectors a separate Python implementation computed.
