The code explorer

On reading every file of the repository, and walking it in the order it runs.

Every file is here, whole, with the editor's line numbers: pick one, or walk a trail, one flow told declaration by declaration in the order it runs. Start with the whole flow, F, which follows one reply from the host's call to its release. Beside next on this trail, each of its steps routes into the trails that tell that stage in depth, and each of their steps routes back. Paste a name, a signature line or a whole body into the box to open that declaration with what it calls and what calls it. Calls are matched by name and argument labels, not by a compiler, and each says how sure it is; Copy line gives File.swift:21 for the editor's Open Quickly.
